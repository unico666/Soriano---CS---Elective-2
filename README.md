# instagram_layout_recreation

A static Instagram post screen layout recreated in Flutter using basic
widgets (`Container`, `Row`, `Column`, `Text`, `Icon`).

Built for the CS Elective 2 activity — recreates the assigned mobile
application screen layout and color palette.

## Getting Started
